ABOUT THE DATASET

Arrangement and melody,
aligned as one system.

The combined Jazz MIDI and MulTTiPop release contains 1,242 usable MIDI arrangements after overlap-aware duplicate removal and low-quality-track filtering. Of these, 509 arrangements contain all four core instrument tracks—piano, guitar, bass and drums—plus a separate melody track, while 733 other usable arrangements contain supported partial combinations of these five roles. The synchronized multi-track data is useful for arrangement analysis, accompaniment generation, melody conditioning, track separation and multi-track music modeling.
