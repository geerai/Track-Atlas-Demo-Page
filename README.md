# Track Atlas

An interactive browser-based inspector for selected arrangements from the combined Jazz MIDI and MulTTiPop dataset.

The demo visualizes and synthesizes synchronized piano, guitar, bass, drums, and melody tracks directly in the browser.

## Live demo

After GitHub Pages is enabled, the site will be available at:

https://geerai.github.io/Track-Atlas-Demo-Page/

## Run locally

Open `index.html` in a modern browser. Keep `index.html`, `styles.css`, `app.js`, and `data.js` in the same directory.

See [USAGE.md](USAGE.md) for playback instructions and troubleshooting.
